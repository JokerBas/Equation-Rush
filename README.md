Equation Rush 🎮 (Beta 0.0.1)

Equation Rush คือเกมคณิตศาสตร์บนเว็บ (Browser Game)  
พัฒนาด้วย JavaScript เพื่อฝึกพื้นฐานการเขียนเกม การจัดการ logic และ game state

Repository นี้ใช้เพื่อแสดงกระบวนการเรียนรู้และพัฒนาทักษะของผมในฐานะ  
**Junior Game Developer (ผู้เริ่มต้น)**

---

## 🤖 การใช้ AI ในโปรเจกต์นี้

โปรเจกต์นี้เป็นเกมแรกที่ผมสร้างขึ้น  
ในช่วงเริ่มต้น ผมยังไม่คุ้นเคยกับโครงสร้างการเขียนเกมและการจัดการ logic

ผมใช้ AI เป็นเครื่องมือช่วยในการ:
- สร้างตัวอย่างโค้ดสำหรับการคำนวณและ game logic เบื้องต้น
- อธิบายแนวคิดและลำดับการทำงานของโค้ด

หลังจากนั้น ผมได้:
- อ่านและพยายามทำความเข้าใจโค้ดทีละส่วน
- แก้ไขโค้ดบางส่วนให้ตรงกับพฤติกรรมของเกม
- Debug ปัญหาที่เกิดขึ้นระหว่างการพัฒนา

โปรเจกต์นี้จึงเป็นส่วนหนึ่งของกระบวนการเรียนรู้  
และกำลังอยู่ระหว่างการปรับปรุงโครงสร้างโค้ด (refactor)

## 🧠 สิ่งที่ได้เรียนรู้
- การจัดการ game flow และ game state ด้วย JavaScript
- ความสำคัญของโครงสร้างโค้ดที่อ่านง่ายและดูแลต่อได้
- การแก้บั๊กและปรับปรุงโค้ดแบบเป็นขั้นตอน
- การพัฒนาแบบเรียนรู้ไปพร้อมกับลงมือทำจริง
